# Changelog

## 0.3.1 — 2026-10-08

- Clarify first-use guidance and explain how the Bible map represents reading
  history, without repeating the app slogan throughout working screens.
- Rename sample content to Sample readings and make Verse list help easier to
  find.
- Explain reading counts and patterns, including overlapping passages and
  readings copied between journals.
- Give filtered views and archived journals clearer empty states and recovery
  guidance.
- Clarify backup, import, browser storage, and display settings guidance.
- Refresh source and ready-to-host release archives and version labels.

Existing journals and readings continue to use database schema 3 and backup
format 3. Readings remain in your browser; export all journals to back up or
transfer your history.

## 0.3.0 — 2026-10-08

- Apply the updated design system across desktop and mobile, with consistent
  typography, spacing, controls, and shared reading detail surfaces.
- Make reading workflows clearer: Log a reading shows its destination journal;
  View readings provides explicit Apply, Cancel, and Reset controls; Your data
  keeps backups and recovery together.
- Improve map exploration with Go to passage, Map display, Inspect a verse,
  keyboard navigation, and accessible text exploration.
- Refresh Reading history and Reading patterns, with shared reading details,
  contextual actions, and an expandable breakdown of all 66 books.
- Improve dialog focus handling, responsive layouts, contrast, and reduced-motion
  support, backed by browser and visual regression checks.
- Refresh source and ready-to-host release archives and version labels.

Existing journals and readings continue to use database schema 3 and backup
format 3. Readings remain in your browser; export all journals to back up or
transfer your history.
